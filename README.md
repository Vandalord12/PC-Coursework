# MMA: A CSV Query Language

MMA is a domain-specific programming language created for querying and ma-
nipulating data stored in Comma-Separated Value (CSV) documents. Designed
with usability and practicality in mind, MMA offers a concise and expressive
syntax that enables users to filter, select, sort, join, and aggregate data directly
from CSV files without the need to load them into a full-fledged relational
database system.
Inspired by the familiarity and power of Structured Query Language (SQL),
MMA adopts many of its core concepts and constructs, including SELECT,
WHERE, JOIN, and ORDER BY. However, it tailors these features to the
lightweight and often irregular structure of CSV files. This blend allows users
with prior SQL experience to quickly adapt to MMA, while also simplifying
the learning curve for newcomers focused on data exploration and manipulation
tasks.
By building on SQL’s strengths and adapting its syntax for CSV-centric use
cases, MMA strikes a balance between expressiveness and simplicity, making
it an effective tool for working with flat-file datasets in a direct and efficient
manner.
